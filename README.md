# Decap Adjustment 2.1.0

Cadence Sigrity SPD의 decap 상태·부품 배치를 검토하고 조정하는 한국어 Windows 앱. SPD를 열고 두 작업 탭에서 같은 작업 상태를 편집한 뒤, 검증된 변경을 새 SPD 파일로 저장.

## 설치

[최신 GitHub Release](https://github.com/yunhyok/decap-adjustment/releases/latest)에서 `DecapAdjustment-2.1.0-Setup-x64.exe`를 내려받아 실행. Python과 Excel 설치 불필요.

- Windows 10/11 x64 대상. ARM64 네이티브 실행 및 macOS 설치 패키지는 미지원.
- 새 설치 기본 위치는 `C:\Program Files\Decap Adjustment`. 설치 화면에서 다른 드라이브나 폴더 선택 가능.
- 설치 파일은 서명되지 않음. Windows가 알 수 없는 게시자 경고를 표시할 수 있음. Release의 SHA-256 파일로 확인 가능.
- 제거는 Windows 설정의 **설치된 앱 → Decap Adjustment**에서 실행.

## 빠른 사용

1. **SPD 열기…**에서 `.spd`를 열고 **거리 기준 · 대상…**에서 기준 부품과 대상 decap 부품 종류를 지정.
2. **명령 목록** 탭에서 NET·채널·사이트·부품을 검색하고 표의 행을 선택한 뒤 `A-2,D+1` 형식의 명령을 큐에 추가. **명령 Excel 가져오기…**는 현재 큐에 명령을 추가함.
3. **배치 · 변환** 탭에서 재배치·변환 등 설정을 확인. **계산 미리보기**에서 변경 RefDes, NET별 수량, 검증 결과를 확인.
4. 검증 통과 후 **명령 결과 적용 · 두 탭에 반영**을 눌러 미리보기 결과를 현재 작업에 반영. 적용 후 명령 큐는 비워짐.
5. **도면 · 직접 선택** 탭에서도 물리 자리의 상태를 바로 바꿀 수 있음. **SPD 다른 이름으로 저장…**으로 새 파일 생성.

거리 기준·대상을 변경하면 확인 후 처음 연 SPD에서 새 작업 시작. 저장한 변경을 이어가려면 저장된 SPD를 열 것.

미리보기는 적용 전 상태. 적용하지 않은 명령은 저장되지 않으며, 저장 시 확인 창에서 현재 두 탭에 반영된 상태만 저장할 수 있음. 기존 파일을 덮어쓰지 않으며, 이미 있는 이름을 고르면 안내 후 다시 물음. 원본 SPD가 불러온 뒤 바뀌면 저장을 거부함. 별도 검증·감사 보고서는 생성하지 않음.

**편집 → 실행 취소 / 다시 실행** 또는 `Ctrl+Z` / `Ctrl+Y`(`Ctrl+Shift+Z`)로 설정, 명령 큐, 부품 정보, 상태 편집을 되돌리기. 계산 결과 적용과 도면 직접 선택은 두 탭의 공통 작업 상태를 갱신.

창 크기와 표 행 높이는 Windows 디스플레이 배율(100–200%)에 맞춰 조정하며, 화면보다 큰 창을 만들지 않음. 하단의 상태 줄과 저장 버튼은 창 높이와 관계없이 항상 표시함.

## 탭과 조정 방식

### 거리 기준 · 수량 조절

- 공통 SPD에서 고른 기준 부품·대상 부품을 바탕으로 같은 NET의 pad와 pin 사이 최단 거리(µm) 계산. 배선 길이나 부품 중심 간 거리가 아님.
- `A`는 가까운 자리부터, `D`는 먼 자리부터 선택. `+N`은 활성화, `-N`은 비활성화. 예: `A-2,D+1`.
- 같은 NET·부품의 순차 명령은 한 행에서 쉼표로 연결할 것. 동일 NET·부품의 중복 행은 직접 추가 시 바로 거부하고, 가져온 명령과 겹치면 계산에서 오류 처리. 명령을 직접 추가·수정·삭제하거나 `.xlsx` 명령표를 가져오기. Excel 명령은 편집 가능한 큐에 이어 붙음. Excel은 명령 가져오기에만 사용.
- **배치 · 변환**에서 선택 NET, 재배치 우선순위, 부족분 변환 규칙과 별칭 관리.
- 계산 미리보기에서 변경 내역, NET·부품별 자리와 활성 수량, 오류·경고 검토. 검증 실패 시 적용할 수 없으며 원인을 제목 줄과 **검증 · 선택 근거** 탭에 표시.
- 재배치로 다른 자리로 옮겨지는 상태 중 SPD에 기록할 수 없는 값(인식하지 못한 `Usage`)은 활성(`Automatic`)으로 옮김. 옮겨지지 않는 자리의 원래 값은 유지.

### 도면 · 직접 선택

- SPD 물리 좌표의 기준 부품·대상 decap pad와 부품 몸체를 표시. 구리 면(mesh)이나 배선 형상은 표시하지 않음. 기준 부품의 핀은 위치 참고용으로 모든 면 보기에 표시.
- `Top`, `Bottom`, `Unknown` 면 선택. `Bottom 좌우 반전 (X)`은 Bottom 보기에서 사용.
- 클릭·드래그로 선택하고 Ctrl을 누른 채 선택을 추가. 검색 표에서 채널·사이트·NET·RefDes·크기·용량 조회.
- 표에 기준 핀까지 거리(µm) 표시. 열 제목 클릭으로 정렬, 행 더블클릭으로 도면을 그 자리로 이동, `Ctrl+A`로 표시된 행 전체 선택.
- 선택 자리의 상태를 `Automatic`으로 활성화하거나 `Disabled`로 비활성화. 변경은 거리 기준 탭의 수량·계산 상태에도 즉시 반영.
- 면 정보가 불명확한 부품은 `Unknown` 보기에 표시. 사용자가 면을 임의로 지정하지 않음.

## 부품 크기·용량 정보

프로그램은 SPD 내 `.PartialCkt` SPICE 주석의 `Description`, `Property`, `Nominal Capacitance`, `Case Size`, `Package`, `Size` 등의 표기에서 공칭 용량과 크기를 읽음. 표기가 없거나 해석할 수 없으면 `미인식`으로 유지. 부품명만 보고 용량이나 크기를 추정하지 않음.

**부품 정보…**에서 부품 종류별 크기와 용량을 수동 입력할 수 있음. 용량은 `100nF`, `4.7uF`처럼 단위와 함께 입력하며 숫자만 쓰면 pF. 불러온 정보로 복원은 파일을 열 때의 값으로 되돌리는 기능. 수동 정보는 SPD에 `DecapAdjustment TypeMetadata` 특수 주석으로 저장하며 회로 모델 값과 연결 상태는 변경하지 않음.

## SPD 저장 범위

- 원본 SPD는 보존. 새 경로에 저장하며 이미 존재하는 경로는 거부.
- 상태 변경은 SPD의 `Usage` 값으로 반영. 허용되는 조정 상태는 `Automatic`, `Enabled`, `Disabled`.
- 부품 종류 변경은 SPD에 포함된 `.Part` 형상·모델 핀 구성이 호환될 때만 허용.
- 미적용 명령은 SPD에 기록하지 않으며 저장 전 확인 창을 표시.
- 수동 용량·크기 정보는 특수 주석으로 저장. 회로 모델 값과 전기적 연결은 그대로 유지.

## 개발 및 빌드

Python 3.12.10 x64 기준. 개발 환경에서 실행 및 테스트:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-build.txt
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python run_app.py
```

Windows 설치 프로그램 빌드:

```powershell
.\packaging\build.ps1
```

패키징 과정과 검증 항목은 [Windows 패키징 안내](packaging/README.md) 참조. 합성 예제는 `examples/`에서 확인.
