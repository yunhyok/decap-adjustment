파일과 대상 범위

SPD 열기…에서 Cadence Sigrity SPD 파일을 연 뒤 거리 기준 · 대상…에서 기준 부품과 대상 decap 종류를 지정할 것. 두 작업 탭은 같은 SPD와 작업 상태를 사용함.

거리 기준은 같은 NET에 연결된 부품 pad와 기준 pin 사이의 최단 XY 거리이며 µm 단위. 배선 길이나 부품 중심 간 거리가 아님.

1 / 거리 기준 · 수량 조절

명령 목록

NET, 채널, 사이트, 부품명으로 대상을 검색할 것. 위 표에서 행을 선택하면 NET과 부품이 입력란에 채워지며, 더블클릭 또는 Enter로 명령 입력란으로 이동함. A +/- N 또는 D +/- N 명령을 큐에 추가·수정·삭제할 것.

  • A: 가까운 자리부터 선택. D: 먼 자리부터 선택.
  • +N: 활성화. -N: 비활성화. 예: A-2,D+1.
  • 같은 NET·부품의 명령은 한 행만 허용함. 이미 있는 조합을 다시 추가하면 거부하므로, 해당 행을 선택해 선택 수정으로 쉼표로 이어 쓸 것.
  • 명령 Excel 가져오기…는 명령만 읽어 현재 편집 가능한 큐 뒤에 추가함. 기존 큐를 대체하지 않음.
  • 명령 Excel은 증감 명령 입력용. RefDes나 distance 표를 불러오거나 Excel 보고서를 저장하지 않음.

배치 · 변환

선택 NET, 재배치 여부와 우선순위, 부족분 변환 규칙을 설정할 것. 부품 이름이 다른 경우 별칭 편집…에서 명령표 이름 = 실제 부품명을 한 줄에 하나씩 지정할 것. 이름을 자동 추측하지 않음.

재배치로 다른 자리로 옮겨지는 상태 가운데 SPD에 기록할 수 없는 값(인식하지 못한 Usage)은 활성(Automatic)으로 옮겨짐. 옮겨지지 않는 자리의 원래 값은 그대로 유지함.

계산 미리보기

변경 RefDes·상태·부품, NET·부품별 자리 수량과 검증 결과를 검토할 것. 성공한 미리보기 결과는 아직 작업 상태에 적용되지 않음. 명령 결과 적용 · 두 탭에 반영을 눌러 적용할 것. 적용된 명령 큐는 비워짐.

검증 오류가 있으면 적용 불가. 실패 원인은 제목 줄과 검증 · 선택 근거 탭에 표시됨. 자리 부족 선택이나 변환 설정을 조정하고 다시 계산할 것.

2 / 도면 · 직접 선택

SPD 물리 좌표에 있는 대상 pad와 부품 몸체를 표시함. 구리 면(mesh)이나 배선 형상은 표시하지 않음.

  • 표시할 면을 Top, Bottom, Unknown으로 전환할 것. 면은 SPD 정보에서 판별하며 사용자가 위치 면을 지정할 수 없음. Bottom 보기에는 Bottom 좌우 반전 (X) 옵션 제공.
  • 마우스 클릭·드래그로 자리를 선택하고 Ctrl+클릭 또는 Ctrl+드래그로 선택을 추가할 것.
  • 검색 표에서 채널, 사이트, NET, RefDes, 기준 핀까지 거리(µm), 크기와 용량을 확인할 것. 열 제목을 누르면 오름차순 → 내림차순 → 원래 순서로 정렬함.
  • 표의 행을 더블클릭하면 도면이 그 자리로 이동·확대됨. 표에서 Ctrl+A는 표시된 행 전체 선택, Esc는 선택 해제.
  • 기준 부품의 핀은 위치 참고용으로 모든 면 보기에 표시됨. 선택 대상은 아님.
  • 선택한 자리를 Automatic으로 활성화하거나 Disabled로 비활성화할 것.

도면 편집은 선택한 RefDes의 실제 상태를 바꾸며 거리 기준 탭에도 즉시 반영됨. SPD에서 면을 판별하지 못한 자리는 Unknown 보기에서 확인할 것.

부품 크기·용량

SPD의 .PartialCkt SPICE 주석에서 공칭 용량과 크기를 읽음. Description, Property, Nominal Capacitance, Case Size, Package, Size 등의 표기를 지원함.

정보가 없거나 인식하지 못하면 미인식으로 유지. 부품명만으로 크기·용량을 추정하지 말 것. 부품 정보…에서 종류별 크기와 용량을 직접 입력 가능. 용량은 100nF, 4.7uF처럼 단위와 함께 쓰며, 숫자만 쓰면 pF로 읽음.

수동 정보는 SPD의 DecapAdjustment TypeMetadata 특수 주석으로 저장됨. 회로 모델 값과 전기적 연결은 변경하지 않음.

적용, 실행 취소, 저장

편집 → 실행 취소 / 다시 실행, Ctrl+Z / Ctrl+Y로 명령 큐, 설정, 수동 부품 정보와 상태 편집을 되돌릴 것. 변경은 두 탭에 함께 반영됨.

SPD 다른 이름으로 저장…은 현재 적용된 상태만 새 SPD 파일로 저장함. 미적용 명령은 저장되지 않으며, 미적용 명령이나 성공한 미리보기가 있으면 확인 창이 표시됨. 원본을 보존하고 기존 파일도 덮어쓰지 않음. 이미 있는 이름을 고르면 안내 후 다시 묻고, 기본 이름은 쓰이지 않은 이름(_adjusted, _adjusted_2 …)으로 제안함.

저장 후에도 이 창의 작업은 처음 연 원본 SPD 기준으로 계속됨. 저장한 파일에서 이어서 작업하려면 그 파일을 열 것.

원본 SPD가 불러온 뒤 변경되면 저장을 거부함. 별도 Excel 검증·감사 보고서는 생성하지 않음.

단축키

  • Ctrl+O: SPD 열기. Ctrl+S: SPD 다른 이름으로 저장. F1: 도움말.
  • Ctrl+Z: 실행 취소. Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행.
  • 명령 입력란에서 Enter: 명령 추가. 명령 목록에서 Delete: 선택 명령 삭제.
  • 대화상자에서 Esc: 닫기. 도움말 창에서 Ctrl+F: 문서 검색.
