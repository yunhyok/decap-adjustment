## 오류 수정

- **저장 버튼·상태 줄이 창 밖으로 잘리던 문제.** 창 크기가 픽셀로 고정되어 있어 Windows 디스플레이 배율 125–200%나 1366×768 화면에서 하단의 `SPD 다른 이름으로 저장…`, `계산 · 미리보기`, 도면 탭의 `선택 활성화 / 비활성화`가 보이지 않았음. 창 크기·표 행 높이·열 너비를 배율에 맞추고 화면보다 큰 창을 만들지 않으며, 하단 버튼 줄은 창 높이와 관계없이 항상 표시. Excel 열 확인 창과 자리 부족 선택 창의 확인 버튼, `배치 · 변환`의 변환 규칙 목록도 같은 원인으로 가려지던 것을 함께 수정.
- **인식하지 못한 `Usage` 값이 있는 SPD에서 재배치 결과를 적용할 수 없던 문제.** 재배치가 `Unknown` 상태를 다른 자리로 그대로 옮겨 "저장할 수 없는 상태" 오류로 미리보기가 실패했음. 다른 자리로 옮겨지는 경우 활성(`Automatic`)으로 옮기고, 옮겨지지 않는 자리의 원래 값은 유지.
- **덮어쓰기 확인 후 저장이 거부되던 문제.** 이미 있는 파일을 고르면 Windows가 덮어쓸지 물은 뒤 프로그램이 저장을 거부했음. 덮어쓰기 질문을 없애고, 이미 있는 이름이면 안내 후 다시 묻도록 변경. 기본 파일 이름은 쓰이지 않은 이름(`_adjusted`, `_adjusted_2` …)으로 제안하고 마지막 저장 폴더를 기억.
- **Python 내부 오류 문구 노출.** 별칭 입력(`not enough values to unpack`)과 용량 입력(`could not convert string to float`) 오류를 한국어 안내로 교체.
- SPD를 열기 전에 `부품 정보…`를 눌러도 반응이 없던 문제: 파일을 열기 전에는 비활성화.
- Caps Lock이 켜져 있으면 `Ctrl+Z / Y / S / O`가 동작하지 않던 문제. `Ctrl+Shift+Z` 다시 실행 추가.
- 새 SPD를 열어도 이전 파일의 검색어·NET·부품 입력값이 남아 목록이 비어 보이던 문제.
- 합성 예제를 연 직후 종료할 때 "저장하지 않은 작업" 확인이 뜨던 문제.
- 검증 메시지에 남아 있던 v1.x 용어(`Excel 행`, `RefDes 파일`, `내보낼 수 없습니다`)를 SPD 기준으로 정정.
- 다크 테마에서 흰색으로 표시되던 스크롤바·진행 막대, 밝은 배경이던 범위 지정·별칭·용량 대화상자를 테마에 맞춤. 대화상자는 주 창 가운데에 표시하고 `Esc`로 닫을 수 있음.

## 사용성 개선

- 계산 실패 시 원인을 미리보기 제목 줄에 표시하고 `검증 · 선택 근거` 탭을 자동으로 열어 줌. 적용 후에는 "적용 완료 · N개 RefDes"로 결과를 표시.
- 같은 NET·부품 명령을 다시 추가하면 계산 단계가 아니라 추가 시점에 안내. 명령 표기는 `A-2,D+1` 형태로 정리해 목록에 표시.
- 명령 목록 위 표에서 행을 더블클릭하거나 `Enter`를 누르면 명령 입력란으로 이동.
- 용량을 `100nF`, `4.7uF`처럼 단위와 함께 입력 가능(숫자만 쓰면 pF). 표에는 `4.7 µF` 형태로 표시.
- 도면 탭 표에 기준 핀까지 거리(µm) 열 추가. 열 제목 클릭 정렬, 행 더블클릭으로 도면을 그 자리로 이동·확대, `Ctrl+A` 전체 선택.
- 기준 부품의 핀을 Top·Bottom·Unknown 모든 면 보기에 위치 참고용으로 표시. 선택한 자리는 다른 자리 위에 그림.
- 범위 지정 창에 부품 종류별 용량·사이즈와 선택 합계(종·자리 수) 표시.
- 거리 값은 소수 첫째 자리까지 표시. 창 제목에 열린 파일 이름 표시. 도움말 창은 하나만 열림.
- 합성 예제 보드를 실제 0603M 부품 간격으로 다시 작성해 도면 탭에서 겹치지 않게 함.

## 검증

- 자동 테스트 198개, 하위 테스트 239개 통과. Linux Tk에서 100%(1600×1200, 1366×768, 1024×768), 125%(1366×768), 150%(1920×1080, 1280×720) 화면으로 각각 실행하고, Windows에서는 GitHub Actions(windows-2022)로 실행.
- 변경분을 별도로 코드 리뷰해 찾은 7건(작은 화면의 대화상자 버튼, 정렬 성능, 실행 취소 뒤 제목 문구 등)을 반영.
- 3,000자리·약 200 MB 합성 SPD로 열기 → 범위 지정 → 명령 → 미리보기 → 적용 → 도면 선택 → 부품 정보 → 저장 → 재열기 일치 확인.
- 릴리스 workflow에서 설치·실행·제거, 기본/다른 드라이브 설치 경로, v2.0.0에서의 업그레이드 검증.

## 사용 시 참고

- 실제 제품 SPD로는 검증하지 않음. 이번 수정은 합성 SPD와 자동 테스트 기준이며, SPD 구문 해석 방식은 변경하지 않음.
- Cadence에서 저장 결과를 다시 열어 확인하는 실기 검증은 수행하지 않음.
- 화면 확인은 Linux의 Tk에서 수행함. Windows 실기 화면은 자동 테스트와 설치 검증만 거침.
- 세로 768픽셀 화면에서 배율을 125% 이상으로 쓰면 버튼은 모두 보이지만 목록이 한두 행만 표시될 수 있음. 창을 최대화하거나 배율을 낮추면 됨.
- 설치 파일은 코드 서명되지 않음. 함께 제공한 SHA-256 파일로 다운로드 무결성 확인 가능.
